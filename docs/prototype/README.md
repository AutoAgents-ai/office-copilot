# Office Copilot · 交互原型

零依赖的静态 HTML 原型，验证「首页 → 新建文档 → 左侧工作台 + 右侧 Copilot → 应用修改 → 预览/导出」的核心体验。

## 运行

```bash
open docs/prototype/index.html
```

不需要安装依赖或启动服务。推荐窗口宽度 1280px 以上，1440 × 900 为设计基准。

也可以直接带路由打开某一页：

- 首页：`index.html#/home`
- 我的文档：`index.html#/docs`
- 模板中心：`index.html#/templates`
- 资料库：`index.html#/materials`
- Word 工作台：`index.html#/doc/word`
- PPT 工作台：`index.html#/doc/ppt`
- Excel 工作台：`index.html#/doc/excel`

## 5 分钟演示脚本

1. **首页**：查看数据概览（文档 / 模板 / 资料引用 / 存储）、最近文档、推荐模板与三种文档的快捷新建。
2. **新建文档**：点击「新建文档」→ 选择「演示文稿」→ 选择「季度业务汇报」→ 选择主题 → 输入标题 → 创建。
3. **工作台**：左侧是幻灯片画布与缩略图，右侧是 Copilot。顶栏可改标题、分享、导出；工具栏可切换主题、放映。
4. **对话**：点击 Copilot 的建议或直接发送消息。观察工具调用时间线（联网搜索 / 读取资料 / 生成幻灯片）、流式回复与产物卡片。
5. **应用与撤销**：点击产物卡片「应用到文档」→ 幻灯片变为 8 页 → 画布高亮变更 → 点击「撤销」恢复。
6. **预览**：工具栏「放映」进入全屏演示；Word / Excel 的「预览」进入阅读/只读模式。
7. **导出**：点击「导出」选择格式与范围 → 开始导出 → 完成状态。原型只模拟流程，不生成真实文件。
8. **模板中心**：侧边栏进入模板中心，按类型筛选，点击任意模板会带着类型与模板打开新建面板。
9. **主题**：Word / PPT / Excel 工具栏的「主题」可切换全局主题；AI 生成内容会遵循当前主题。

## 交互地图

| 区域 | 可交互内容 |
| --- | --- |
| 首页 | 数据概览、快捷新建、最近文档、收藏、全部文档筛选/搜索、模板中心、资料库、回收站 |
| 新建面板 | 三种类型、空白/模板、主题、标题、创建 |
| 工作台顶栏 | 返回、标题重命名、分享、导出、更多菜单（预览/主题/复制链接） |
| 左侧画布 | Word 富文本编辑；PPT 幻灯片切换与文本编辑；Excel 单元格编辑、选中、公式栏 |
| 编辑器工具栏 | 撤销/重做、格式命令、主题、预览/放映；不支持的按钮会给出演示提示 |
| Copilot | 上下文芯片、建议动作、发送、停止、重新生成、工具调用展开、资料添加/移除、联网开关、新对话、面板折叠与拖拽调宽 |
| 产物卡片 | 预览生成结果、应用到文档、撤销、重新生成 |
| 预览 | Word 阅读视图、PPT 全屏放映（方向键/Esc）、Excel 只读 |
| 导出 | 格式、范围、引用附录、文件名、进度、完成、下载提示 |
| 资料库 | 上传入口、资料列表、添加资料到对话 |

快捷键：`⌘/Ctrl + Enter` 发送，`⌘/Ctrl + S` 保存，`⌘/Ctrl + K` 聚焦搜索，`Esc` 关闭弹层/退出预览，`←/→` 翻页。

## 覆盖范围

- 首页、我的文档、模板中心、资料库、回收站
- 首页数据概览：文档、模板、资料引用与存储统计，随原型内的新建/上传操作更新
- 新建文档：Word / PPT / Excel × 空白/模板 × 主题 × 标题
- 三种工作台与类型化工具栏
- 左侧大画布 + 右侧 Copilot 的可折叠、可拖拽布局
- Copilot：对话、工具调用可视化、联网开关、资料、流式输出、产物卡片、应用/撤销
- Word / PPT / Excel 三种预览形态
- 导出流程与「导出使用快照」提示
- 模板与主题切换（原型收录 8 套已实现的代表性模板；产品规划中的其余模板见 PRD 版本规划）
- 基础响应式（≤ 1240 / 1080 / 920 / 760）

## 原型边界

这个原型用于**需求与交互评审**，不是完整产品实现：

- AI 回复、联网搜索、资料读取、公式计算均为脚本化演示数据；不调用真实模型或搜索服务。
- 导出是交互模拟，不会生成真实的 `.docx/.pptx/.xlsx` 文件。真实导出由服务端 Doc Model → OOXML 生成，详见 PRD 第 7.2 节（EXP-01/02）与第 12 节。
- 数据保存在内存中，刷新后重置；没有账号、后端、权限与多人协作。首页数据概览由原型内置数据计算，不是真实工作区统计。
- PPT 的精细排版（元素拖拽、对齐线、层级）仅呈现视觉方向，未实现完整编辑器。
- Excel 只实现基础单元格编辑与静态图表，未实现公式引擎。
- 分享、复制链接、上传资料等入口为界面示意。

## 设计要点

- **文档是主角**：左画布占据绝对主区域，Copilot 固定在右侧，宽度可调、可收起，避免打断写作。
- **可感知的 AI**：工具调用、来源、生成规模、应用范围都在对话中可见；应用前可预览，应用后可撤销。
- **从结构开始**：新建流程先选类型与模板，再进入工作台；模板决定内容骨架，主题决定视觉。
- **三种文档三种画布**：Word 是页面，PPT 是 16:9 幻灯片 + 缩略图，Excel 是网格 + 公式栏 + 图表。
- **克制的视觉**：中性灰画布 + 白色内容卡 + 类型主题色（Word 蓝 / PPT 橙 / Excel 绿）。
