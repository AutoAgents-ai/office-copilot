# Office Copilot

AI 原生的 Office 文档工作台：创建、编辑、预览并导出真正的 Word / PowerPoint / Excel 文档，由左侧文档工作区与右侧 Copilot 共同完成。

本仓库当前包含产品需求与可交互的 HTML 原型：

- [产品需求文档（PRD）](docs/PRD.md)
- [HTML 交互原型](docs/prototype/index.html)
- [原型使用说明](docs/prototype/README.md)

## 本地查看原型

原型是零依赖的静态页面，直接用浏览器打开即可：

```bash
open docs/prototype/index.html
```
